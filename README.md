# Random Quote Generator 🎲

A simple web app that generates random inspirational quotes with a click of a button. 

## 📸 Preview 
https://github.com/user-attachments/assets/e7d6a7e7-6d5f-4871-a67d-5efaa5a61440

## Features
- Displays randome quotes from a predefined list
- Shows quotes + author
- Avoids repeating the same quote twice in a row
- Smooth hover and click button effects
- Responsive centered UI

## Built with
- HTML5
- CSS3 (Flexbox, gradients, transitions)
- JavaScript (DOM manipulation, arrays, randomization)

## How it works 
1. A list of quotes is stored in a JavaScript array of objects.
2. When the button is clicked:
   - A radnom index is generated
   - It ensures the same quote is not shown twice in a row
3. The quote and author are updated in the DOM.

## How to run
1. Download or clone this repository.
2. Open `index.html` in any browser.
3. Click **New wuote** to generate quotes.
